# ISC — International Student Cell, MUJ

A polished, responsive website concept based on the supplied MUJ ISC information. Open `dist/index.html` in a browser; no installation or build is needed.

The site includes a custom Canvas globe with spherical projection, dotted land geometry, animated illustrative routes, pointer and keyboard controls, pause/resume behavior, and reduced-motion support. It also includes scroll reveals, a progress indicator, active-section navigation, parallax imagery, responsive mobile navigation, accessible native dialogs and pointer-aware opportunity cards.

Program cards open accessible native dialogs. Official MUJ and LinkedIn links provide the next step; there are no invented application forms, deadlines, statistics or partnership claims. The globe routes are visual storytelling rather than a partner map.

Google Fonts and the MUJ campus image require an internet connection; system fonts and a background color provide fallbacks.

To serve locally: `node serve.cjs`, then open http://127.0.0.1:4173.
